Privacy policy

QCTrack backup is a private tool used only by its developer. It asks for one Google permission, drive.file, so it can create and manage only the backup files it creates itself in the user's own Google Drive.

The tool does not read any other file in Google Drive. It does not collect, share, sell or send personal data to anyone. Backup files are encrypted before they are uploaded, and only the owner has the passphrase.

Access can be removed at any time at https://myaccount.google.com/permissions.
